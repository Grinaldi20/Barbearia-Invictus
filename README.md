# Barbearia Invictus 

Landing page moderna e responsiva desenvolvida para barbearias, com foco em apresentação visual, experiência do usuário e captação de clientes.

## 📱 Funcionalidades

- Layout totalmente responsivo
- Navegação suave entre seções
- Seção de cortes e serviços
- Área de contato
- Botão direto para WhatsApp
- Formulário de contato
- Integração de envio de mensagens por e-mail *(em desenvolvimento)*

---

## 🎨 Objetivo do projeto

O objetivo deste projeto foi criar uma landing page profissional para barbearias, focando em:

- identidade visual forte
- performance
- responsividade
- conversão de clientes
